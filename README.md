# KFC — поиск выгодных лотов на МЭТС

Приложение для торговой площадки [МЭТС (m-ets.ru)](https://m-ets.ru). Ищет лоты по фильтрам,
открывает каждый, считает **разницу между начальной и текущей ценой** и сохраняет всё в Excel.

## Как пользоваться

1. Двойной клик по ярлыку **«KFC Поиск лотов»** (синяя иконка) или по **`KFC.bat`**.
   Откроется окно приложения. На новом компьютере запускай сначала `KFC.bat`: он установит
   нужные библиотеки.
2. Выбери фильтры, как на сайте: что ищешь, категорию, регион, цены «от/до», форму торгов.
3. В блоке **«Отбор по разнице»** укажи, насколько лот должен подешеветь. Например, «от 30 %»
   оставит только лоты, у которых цена уже упала на 30 % и больше.
4. Нажми **«Найти»**. Внизу появится процесс поиска с прогрессом, а по окончании — таблица
   и кнопка **«Открыть Excel»**.

### Вкладки
Каждая вкладка — отдельный поиск со своими фильтрами («Квартиры Москва», «Грузовики Юг»…).
«+ Новый поиск» — новая вкладка, двойной клик по названию — переименовать, × — удалить.
Фильтры сохраняются сами.

### Процессы поиска
Каждый запуск — процесс в списке внизу. Пока идёт: **«Остановить»** (найденное сохранится,
можно продолжить позже) или **«Завершить → Excel»** (остановить и сразу выгрузить найденное).
Остановленный можно **продолжить**, **сохранить в Excel** или **удалить** (вместе с его Excel).
Клик по процессу показывает его результаты.

### Даты
- **Начало / конец приёма заявок** — например, только лоты, у которых торги стартуют 1 октября.
- **Цена в период** — по графику снижения видно, до какой цены лот упадёт между выбранными
  датами и с какого числа. Можно отобрать «снижение в этот период от N %» или «мин. цена до N ₽».

### Сколько искать
- **Просмотреть лотов** — например, 50: быстрый поиск по первым 50.
- **Найти подходящих** — например, 10: поиск остановится, как только найдёт 10 подходящих.
- **Какие смотреть первыми** — новые, со скорым концом приёма заявок, дешёвые или дорогие.

Закрыл окно — приложение само завершится через пару минут.

Нужен Python 3.11 или новее ([python.org](https://www.python.org/downloads/)). При установке
отметь галочку «Add python.exe to PATH».

## Как считается «разница»

На торгах посредством **публичного предложения** цена падает по графику: каждый период на N %,
пока не дойдёт до минимальной цены (цены отсечения).

| В Excel | Что это |
|---|---|
| Начальная цена | цена первого периода торгов |
| Текущая цена | цена, по которой можно подать заявку сейчас |
| **Разница, ₽** | начальная минус текущая |
| **Снижение сейчас** | на сколько % текущая цена ниже начальной |
| Мин. цена / Макс. снижение | до какой цены лот может упасть по графику |
| След. снижение / След. цена | когда и до какой цены подешевеет |
| Цена за м² | для недвижимости и земли |

Кроме того, в Excel есть дата начала торгов, число заявок, кадастровые номера, обременения,
должник, управляющий, телефон, email, номер дела и описание. Если задана «Цена в период» —
ещё колонки с ценой в этот период.

Листы Excel:
- **Лоты** — одна строка на лот. Зелёным отмечены новые (`NEW`), жёлтым — подешевевшие с прошлого поиска (`↓`).
- **График цен** — все периоды снижения по каждому лоту; текущий жирным, выбранный период подсвечен.
- **Что искали** — итоги (сколько просмотрено и подошло, чем закончился поиск), все фильтры
  обычными словами, ссылка на тот же поиск на сайте и журнал: когда запускали, останавливали,
  продолжали, сохраняли.

## Скорость

Первый поиск по всей России открывает несколько тысяч лотов и занимает около 20–25 минут.
Открытые лоты запоминаются в `data/lots_cache.json`: график цен у лота не меняется, поэтому
в следующий раз открываются только новые лоты, а текущая цена берётся из поиска на сайте.
Повторный поиск идёт от нескольких секунд до пары минут. Если поиск остановить, в следующий раз
он продолжится с того же места.

Как поиск экономит время:
- лоты одних торгов лежат на одной странице — она скачивается и разбирается один раз на все лоты,
  а все лоты с неё сразу попадают в память;
- условие «цена снизилась от N %» передаётся сайту как «процент снижения от N %»: лоты, которые
  по графику так подешеветь не могут (например, аукционы), сайт отбрасывает сам;
- из страниц вырезается всё лишнее (скрипты, выпадающие списки) — у торгов на 200 лотов
  страница весит до 5 МБ.

Замер на 100 новых лотах: 10 секунд (было 34), на 100 дешёвых из больших торгов — 16 секунд (было 100).

Запросы к сайту идут с небольшой паузой, чтобы не нагружать площадку.

## Проверка

Двойной клик по **`Проверка.bat`** — 29 автотестов без интернета (около 30 секунд): разбор лотов
(публичка, аукцион, торги из нескольких лотов), цена в период, поисковый запрос, лимиты, остановка,
память лотов, Excel. Тесты работают на сохранённых страницах МЭТС из `tests/fixtures`
(персональные данные в них заменены).

Замер скорости на живом сайте:

```bash
python tests/bench_speed.py
```

## Для продвинутых

Консольный запуск (например, по расписанию), фильтры берутся из `config.toml`:

```bash
python kfc.py              # поиск по config.toml
python kfc.py --lots 50    # просмотреть только 50 лотов
python kfc.py --find 10    # остановиться, когда найдено 10 подходящих
python kfc.py --list       # все регионы, категории и статусы
```

```
KFC.bat           запуск приложения
app.py            приложение: локальный сервер + окно (web/index.html)
kfc.py            консольный запуск
config.toml       фильтры по умолчанию и для консоли
mets/runner.py    весь поиск: выдача → лоты → отбор, лимиты, остановка → Excel
mets/describe.py  фильтры словами для листа «Что искали»
mets/search.py    запрос к поиску МЭТС, разбор выдачи
mets/lot.py       разбор страницы лота, расчёт разницы
mets/storage.py   память лотов и история цен
mets/excel.py     выгрузка в Excel
mets/dicts.py     регионы, категории и статусы сайта
```

# KFC — поиск выгодных лотов на МЭТС

Приложение для торговой площадки [МЭТС (m-ets.ru)](https://m-ets.ru). Ищет лоты по фильтрам,
открывает каждый, считает **разницу между начальной и текущей ценой** и сохраняет всё в Excel.

## Как пользоваться

1. Двойной клик по ярлыку **«KFC Поиск лотов»** (синяя иконка) или по **`KFC.bat`**.
   Откроется окно приложения. На новом компьютере запускай сначала `KFC.bat`: он установит
   нужные библиотеки.
2. Выбери фильтры, как на сайте: что ищешь, категорию, регион, цены «от/до», форму торгов.
3. В блоке **«Отбор по разнице»** укажи, насколько лот должен подешеветь. Например, «от 30 %»
   оставит только лоты, у которых цена уже упала на 30 % и больше.
4. Нажми **«Найти»**. Будет видно, как идёт поиск. В конце появится таблица и кнопка **«Открыть Excel»**.

Фильтры запоминаются между запусками. Все выгрузки лежат в папке `output`, прошлые можно открыть
прямо из приложения. Закрыл окно — приложение само завершится через пару минут.

Нужен Python 3.11 или новее ([python.org](https://www.python.org/downloads/)). При установке
отметь галочку «Add python.exe to PATH».

## Как считается «разница»

На торгах посредством **публичного предложения** цена падает по графику: каждый период на N %,
пока не дойдёт до минимальной цены (цены отсечения).

| В Excel | Что это |
|---|---|
| Начальная цена | цена первого периода торгов |
| Текущая цена | цена, по которой можно подать заявку сейчас |
| **Разница, ₽** | начальная минус текущая |
| **Снижение сейчас** | на сколько % текущая цена ниже начальной |
| Мин. цена / Макс. снижение | до какой цены лот может упасть по графику |
| След. снижение / След. цена | когда и до какой цены подешевеет |
| Цена за м² | для недвижимости и земли |

Кроме того, в Excel есть кадастровые номера, обременения, должник, управляющий, телефон, email,
номер дела и описание. На отдельном листе — график снижения цены по каждому лоту.
Зелёным отмечены новые лоты (`NEW`), жёлтым — подешевевшие с прошлого поиска (`↓`).

## Скорость

Первый поиск по всей России открывает несколько тысяч лотов и занимает около 20–25 минут.
Открытые лоты запоминаются в `data/lots_cache.json`: график цен у лота не меняется, поэтому
в следующий раз открываются только новые лоты, а текущая цена берётся из поиска на сайте.
Повторный поиск идёт от нескольких секунд до пары минут. Если поиск остановить, в следующий раз
он продолжится с того же места.

Запросы к сайту идут с паузой, чтобы не нагружать площадку.

## Для продвинутых

Консольный запуск (например, по расписанию), фильтры берутся из `config.toml`:

```bash
python kfc.py              # поиск по config.toml
python kfc.py --pages 2    # быстрая проверка: 2 страницы выдачи
python kfc.py --list       # все регионы, категории и статусы
```

```
KFC.bat           запуск приложения
app.py            приложение: локальный сервер + окно (web/index.html)
kfc.py            консольный запуск
config.toml       фильтры по умолчанию и для консоли
mets/runner.py    весь поиск: выдача → лоты → отбор → Excel
mets/search.py    запрос к поиску МЭТС, разбор выдачи
mets/lot.py       разбор страницы лота, расчёт разницы
mets/storage.py   память лотов и история цен
mets/excel.py     выгрузка в Excel
mets/dicts.py     регионы, категории и статусы сайта
```

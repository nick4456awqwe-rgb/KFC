# KFC — поиск выгодных лотов на МЭТС

Парсер торговой площадки [МЭТС (m-ets.ru)](https://m-ets.ru): находит лоты по фильтрам,
открывает каждый, считает **разницу между начальной и текущей ценой** и выгружает всё в Excel.

## Установка

Нужен Python 3.11+.

```bash
pip install -r requirements.txt
```

## Запуск

- Двойной клик по `run.bat` — поиск по `config.toml`, Excel откроется сам.
- Или из консоли:

```bash
python kfc.py              # поиск по config.toml
python kfc.py --pages 2    # быстрая проверка: 2 страницы выдачи (40 лотов)
python kfc.py --list       # все регионы, категории и статусы
python kfc.py --open       # открыть Excel после выгрузки
python kfc.py --fresh      # заново открыть все лоты, не глядя в кэш
```

Результат: `output/lots_ДАТА.xlsx`.

## Как считается «разница»

На торгах посредством **публичного предложения** цена падает по графику: каждый период на N %
до минимальной цены (цены отсечения). Для каждого лота считается:

| Колонка | Что это |
|---|---|
| Начальная цена | цена первого периода публички (обычно ≈ оценка имущества) |
| Текущая цена | цена, по которой можно подать заявку сейчас |
| **Разница, ₽** | начальная − текущая |
| **Снижение сейчас** | на сколько % текущая цена ниже начальной |
| Мин. цена / Макс. снижение | до какой цены лот может упасть по графику |
| След. снижение / След. цена | когда и до скольки подешевеет |
| Цена за м² | для недвижимости и земли |

Отбор «по разнице» — секция `[filter]` в `config.toml`: например, `min_discount_now_pct = 30`
оставит только лоты, подешевевшие минимум на 30 %.

## Excel

- **Лоты** — одна строка на лот, номер лота кликабелен. Зелёным — новые с прошлого запуска
  (`NEW`), жёлтым — подешевевшие (`↓`, в колонке «Цена была» — прошлая цена).
- **График цен** — все периоды снижения по каждому лоту, текущий выделен жирным.
- **Параметры** — с какими фильтрами сделана выгрузка и ссылка на тот же поиск на сайте.

## Настройки (`config.toml`)

- `[search]` — фильтры сайта: регионы, категории, форма торгов, цены, слова-исключения.
  Регион/категорию можно писать частью названия: `"Краснодарский"`, `"Москва"`.
- `[filter]` — отбор после открытия лота: % снижения, разница в ₽, дней до конца приёма заявок, цена за м².
- `[run]` — сколько страниц обходить, сортировка, `only_new = true` — только новое с прошлого раза.

## Скорость и кэш

Первый полный обход всех лотов (~4–5 тыс.) занимает около 20–25 минут: каждый лот открывается один раз.
Данные лотов сохраняются в `data/lots_cache.json`, и дальше открываются только новые лоты —
текущая цена берётся из выдачи поиска, а разница пересчитывается по сохранённому графику.
Повторный запуск — несколько минут. Прерванный обход (Ctrl+C) продолжится с того же места.

Запросы к сайту идут с паузой (`delay_sec`), чтобы не нагружать площадку.

## Структура

```
kfc.py            запуск: поиск → открытие лотов → фильтр → Excel
config.toml       настройки
mets/client.py    HTTP-клиент с паузами и повторами
mets/search.py    сборка поискового запроса МЭТС, разбор выдачи
mets/lot.py       разбор страницы лота, расчёт разницы
mets/storage.py   кэш лотов и история цен
mets/excel.py     выгрузка в Excel
mets/dicts.py     коды регионов, категорий и статусов сайта
```
